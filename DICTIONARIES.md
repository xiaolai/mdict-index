# Recommended dictionaries

Generated by `scripts/recommended_doc.py` from `data/recommended.json` (edited by hand,
reviewed 2026-09-29) and the crawled index; do not edit this file, edit the JSON and
run the script. These are the dictionaries the site recommends and the ones
`scripts/fetch_corpus.py` downloads and the local database is built from: 25 with a copy on
freemdict, 20.69 GB in all. ★ marks the starter set the site shows first.

"Copy on freemdict" is the record the build downloads, and the folder of its most complete copy.
"Newest edition" links to the source that says what the newest edition is. Status:

- current: the newest edition
- behind: a newer edition exists, not on freemdict
- snapshot: a dated copy of a work updated online
- final: the last edition there will be
- unclear: the copy's edition cannot be told
- missing: not on freemdict
